# Contributing to @forge-ahead/triggers

Thank you for considering a contribution to @forge-ahead/triggers! Pull
requests, issues, and comments are welcome. For pull requests, please:

- Add public-seam tests for new features and bug fixes.
- Follow the existing style and package boundaries.
- Keep unrelated changes in separate pull requests.
- For changes to trigger contracts, begin with the required red-green-refactor
  sequence in the extraction specification.

For larger changes, start a discussion by creating an issue that explains the
intended outcome and compatibility impact.

Atlassian requires contributors to sign a Contributor License Agreement (CLA).
This records that the contributor is entitled to contribute the
code/documentation/translation and is willing to have it used in distributions
and derivative works (or to transfer ownership).

Before contributions can be accepted, please sign the appropriate CLA:

- [CLA for corporate contributors](https://opensource.atlassian.com/corporate)
- [CLA for individuals](https://opensource.atlassian.com/individual)
